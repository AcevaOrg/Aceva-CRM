## Known limits

1. The baseline is recorded at the first background-worker start with this module in an environment; tests record it
   explicitly. Before it exists, no rule can be set (409 `baseline_missing`) and nothing qualifies.
2. Leavers are not notified of decisions (they no longer have access).
3. The Director's approval of a normal line needs no step-up (only the Owner's decisions, the rule and the leaver
   decision do).
4. The payroll month is the month of approval; Module 8 decides which editable run takes it. How M8 pays a leaver whose
   line is approved after their last run is an open M8 question.
5. Pre-existing, not changed here: the M15.6 notification types `sales_daily_report` and `sales_proof_requested` have no
   label or icon on the frontend notification screen (they show with the default bell).
