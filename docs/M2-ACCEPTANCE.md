## Things to know

- **Lost authenticator phone:** the plan has no recovery procedure and none is built. The account screen says to ask the Director or HR.
  Needs a decision (suggestion: Director or HR can reset 2FA for people below them, audited, forcing a new set-up).
- **Temporary password only without an official email** (as the plan says). If someone has an email but cannot reach the mailbox, there
  is currently no route for them.
- **Time-limit tests use a movable clock**, not a real 30-minute wait.
- **Idle timer on the screen vs. the server:** the screen sends a "still here" request each minute only while there was real mouse or
  keyboard activity; the server's idle limit is authoritative.
- **Screens for newly hired people** work once Module 3 (profiles) is live; until then the built-in demo roster supplies names. The
  first-login wizard already reads the name from the server.
- **GitHub Actions** has still never run on GitHub; Redis was added to its definition but that is untested.
